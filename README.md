# Мой Дневник — Full Redesign V2

Локальное Android-приложение на Capacitor 7 + Vite. Данные хранятся на устройстве в `localStorage`; для уведомлений Android подключён Capacitor Local Notifications.

## Что внутри
- Главная панель с прогрессом, целями, задачами, заметками и напоминаниями.
- Цели: создание, изменение, удаление, категории, срок, приоритет, статус и прогресс.
- Задачи: CRUD, отметка выполнения, фильтр, поиск, сортировка по приоритету и сроку.
- Заметки: редактор, поиск, категории, закрепление и временные метки.
- Календарь с событиями из задач и напоминаний, компактным переключателем месяцев и карточками выбранного дня.
- Финансы: отдельный учёт доходов и расходов, баланс, история операций, редактирование/удаление и выбор валюты UAH/USD/EUR.
- Напоминания с датой, временем и повторением (Android Local Notifications).
- Русский, украинский и английский интерфейс.
- Светлая, тёмная и спокойная Sage-тема.
- Статистика, JSON-экспорт и импорт резервной копии (включая финансовые операции).
- GitHub Actions собирает debug APK и публикует его в Artifacts.

## Сборка APK через GitHub с телефона
1. Распакуйте архив и загрузите **содержимое** папки проекта в корень своего GitHub-репозитория. Не загружайте ZIP внутрь репозитория.
2. Убедитесь, что `.github/workflows/build-apk.yml` сохранён по этому пути.
3. Откройте вкладку **Actions** репозитория и разрешите GitHub Actions, если появится запрос.
4. Выберите workflow **Build Мой Дневник APK** → **Run workflow**. Также сборка запускается автоматически при push в `main` или `master`.
5. Дождитесь завершения job с зелёной галочкой.
6. Откройте запуск workflow, найдите **Artifacts** и скачайте `Moy-Dnevnik-APK`.
7. Распакуйте скачанный ZIP и установите `app-debug.apk` на Android. При необходимости разрешите установку приложений из этого источника.

## Важные технические замечания
- Android-папка генерируется на GitHub Actions командой `npx cap add android`; она не хранится в этом исходном архиве.
- После изменения исходников workflow выполняет `npm run build`, затем `npx cap sync android`, включая нативный плагин уведомлений.
- Данные остаются на устройстве при обычном обновлении APK с тем же `appId`, пока пользователь не очищает данные приложения или не удаляет его. Перед крупным обновлением рекомендуется экспортировать резервную копию.
- Уведомления требуют разрешения Android. На Android 13+ система отдельно запрашивает разрешение на уведомления. Для повторов используются механизмы Local Notifications; точное время доставки также зависит от ограничений энергосбережения Android.
- Резервная копия — JSON-файл. Храните её отдельно от телефона.
- Сборка `assembleDebug` создаёт APK для тестовой/личной установки, а не подписанный релиз Google Play.
- Внешние шрифты загружаются из Google Fonts, но системные шрифты остаются fallback-вариантом без интернета.


## Редизайн Light Glass (2026)

В проект добавлен адаптивный интерфейс в стиле Light Glass: полупрозрачные поверхности, мягкие градиенты, увеличенная типографика, обновлённые карточки и кнопки, анимации и мобильная нижняя навигация. В настройках доступны темы Light Glass, Midnight, Sage, Ocean и Rose. Все существующие разделы и механизмы хранения данных оставлены на месте.

Для сборки после установки зависимостей: `npm install`, затем `npm run build`.
